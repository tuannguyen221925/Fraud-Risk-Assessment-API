# Credit Card Fraud Detection

Dự án phát hiện giao dịch thẻ tín dụng gian lận bằng XGBoost.
API cung cấp dự đoán và giải thích dự đoán bằng SHAP.

## Công nghệ

- Python
- Pandas, NumPy
- Scikit-learn, XGBoost
- SHAP
- FastAPI, Pydantic
- Joblib
